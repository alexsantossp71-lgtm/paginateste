# Como contribuir

## Ambiente local

1. Use Node.js 18 ou superior.
2. Copie `.env.example` para `.env` e preencha os valores locais.
3. Execute `npm start` e abra `http://localhost:3000`.

## Antes de enviar alterações

```bash
npm run check
npm test
```

Mantenha as alterações pequenas, descreva a validação realizada e nunca inclua arquivos `.env`, tokens ou dados pessoais no repositório.
