# Política de segurança

Não publique senhas, tokens, chaves da CGU ou dados pessoais em issues, pull requests ou commits.

Para relatar uma vulnerabilidade, abra uma issue privada com o responsável pelo repositório ou remova qualquer dado sensível da reprodução antes de abrir uma issue pública. Credenciais eventualmente expostas devem ser revogadas imediatamente no provedor de origem.
